# Npcalc Dark Cylinder (Java, Android)

A clean dark-theme calculator with cylindrical buttons and unique identifiers, built in Java.

## Build
- Open in Android Studio Hedgehog or newer
- Gradle plugin 8.4, compileSdk 34, minSdk 24
- Run the `app` configuration

## Privacy
- This app does not collect, store, or share personal data.
- No network permissions; offline only.
